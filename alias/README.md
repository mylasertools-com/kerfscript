# kerfscript

**A programming language for laser cutting.**

This package is the same as
[`@mylasertools/kerfscript`](https://www.npmjs.com/package/@mylasertools/kerfscript)
and installs it. Use either name.

```sh
npx kerfscript render box.kerf -o box.svg
```

```js
import { render } from 'kerfscript';
```

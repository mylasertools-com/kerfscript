# Third-party licences: kerfscript.wasm

kerfscript.wasm runs KerfScript's JavaScript on a JavaScript engine that
[Javy](https://github.com/bytecodealliance/javy) v9.1.0 builds into the module:
Javy's javy-plugin crate with QuickJS (through rquickjs) and the Rust crates
below. Each is listed with its licence and the licence files it ships; the
texts follow, each under the crates that share it. KerfScript's own code and
the JavaScript libraries it bundles are covered by LICENSE and
THIRD-PARTY-NOTICES.md.

This file is made by `scripts/wasm-licenses.mjs` from Javy's Cargo.lock.

Every crate's source is available from the link in the Source column:
crates.io keeps each published version. Licence files marked "(added)" are
not in the published crate: they are the licence files of the crate's
repository at the commit it was published from, or the licence text the
crate's source files refer to. packaging/licenses/ keeps them, with where each
came from.
